# 喵騎導航 MeowBikeNavi

用開源地圖（OpenStreetMap）規劃自行車路線的網頁 App。打開網址就能用，不用登入，路線存在自己的手機裡。

## 功能

- 依載具（自行車、機車、汽車）推薦路線；自行車可選「均衡、避開車多的路、避開爬坡、最快抵達」。
- 在地圖上加中途點，每段自動找最佳路徑串起來；中途點可拖曳、刪除、調整順序。
- 每兩點之間的路段可以「固定」：之後加減、移動其他中途點時，固定的路段不重新規劃（移動這段兩端的點才會解除）。
- 單車路段可設為「牽車」：這段改用步行規劃，走地圖資料沒開放單車的路（例如沒標示單車可通行的橋）。路線繞路偏多時，路段下方會提示。
- 固定與牽車設定會跟著路線儲存、匯出 GPX／JSON。
- 儲存路線，之後可原路導航，或反向導航（起點終點對調，路線不變）。
- 手機 GPS 導航：偏離路線時**不會重新規劃**，畫面多一個箭頭指向回到路線的方向。
- 導航資訊卡可按住上下拖曳，位置會記住；自己的位置保持在卡片上方或下方較大的地圖空白區中央。
- 快到轉彎時顯示轉彎提示並用語音提醒（可選聲音、語速、靜音）。
- 路線存放：
  - 預設存在瀏覽器裡（localStorage）。
  - 支援的瀏覽器可改存到手機資料夾，一條路線一個 GPX 檔；選雲端同步的資料夾就能跨裝置同步。
  - 可匯出單條路線（GPX）或全部備份（JSON），在其他手機匯入。

## 瀏覽器支援

| 功能 | Android Chrome | iPhone Safari | 電腦 Chrome／Edge |
|---|---|---|---|
| 規劃、儲存、導航、語音 | 可以 | 可以 | 可以 |
| 路線資料夾模式 | 可以 | 不支援（用匯出／匯入） | 可以 |

Android 的資料夾選擇器不能直接選 Google 雲端硬碟，要同步請先用同步 App（例如 FolderSync、Syncthing）把雲端資料夾同步到手機內的一般資料夾，再在 App 裡選那個資料夾。

## 使用的服務

| 用途 | 服務 |
|---|---|
| 地圖圖磚 | OpenStreetMap 標準圖磚、CyclOSM |
| 路線規劃 | Valhalla 公共伺服器 `valhalla1.openstreetmap.de` |
| 地點搜尋 | Nominatim |
| 地圖元件 | Leaflet 1.9.4（unpkg CDN，含 SRI） |

都是社群提供的免費公共服務，有合理使用限制，不適合大量使用者同時用。

## 本機開發

純靜態網站，沒有建置步驟。

```powershell
python -m http.server 8780 --bind 127.0.0.1
```

打開 `http://localhost:8780/`。網址加 `?sim` 會開啟模擬模式（可在 console 用 `__mbnSim(lat, lon)` 模擬 GPS 位置）。

測試（Node 20 以上）：

```powershell
npm test
```
